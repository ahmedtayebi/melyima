# تحديد الطلبات وتنفيذ العمليات الجماعية

- تبويب «قيد الانتظار»: تحديد طلبات أو تحديد كل النتائج عبر الصفحات، ثم «تأكيد الطلبات المحددة». يُؤكد كل طلب وتُجهز بوليصته كما في العملية الفردية، دون إرساله للشحن.
- تبويب «مؤكدة»: التحديد متاح فقط للطلبات ذات رقم تتبع وحالة بوليصة `draft`. زر «إرسال المحددة للشحن» يعرض تأكيدًا واحدًا يتضمن العدد والإجمالي قبل التنفيذ.
- خانات التحديد متاحة في جدول الكمبيوتر وبطاقات الهاتف. البحث يحافظ على الاختيارات، والانتقال إلى تبويب آخر يمسحها.
- التنفيذ متتابع عبر مسارات API الموجودة، بصلاحيات المسؤول وقفل العمليات وفحص حالة كل طلب على الخادم. لا توجد إعادة محاولة تلقائية لعملية شحن ذات نتيجة غير مؤكدة.
- تعرض النتائج حالة كل طلب، وتبقى الطلبات غير المكتملة محددة. زر مستقل يعيد محاولة غير المكتملة فقط؛ يشمل حالة نجاح التأكيد وفشل إنشاء البوليصة، حتى بعد انتقال الطلب إلى المؤكدات.
- الإيقاف ينتظر اكتمال الطلب الجاري ثم يتوقف قبل الطلب التالي. العملية تعمل ما دامت الصفحة مفتوحة؛ ليست مهمة خلفية دائمة. لم تُرسل شحنات حقيقية أثناء الاختبارات.
- يوضح التقرير نجاح الإرسال مع الحاجة إلى المزامنة، أو إعادة إنشاء البوليصة والحاجة لإعادة طباعتها. تُحفظ الحالة الفعلية عند إعادة محاولة طلب سبق شحنه.
- تحميل الطلبات الأولي وتحديثها يستخدمان صفحات بيانات متتابعة لتجاوز حد استجابة Supabase الافتراضي، ويُرفضان عند فشل التحميل بدل إظهار نتيجة مبتورة على أنها كاملة.
- لا يستطيع تحديث قائمة بدأ قبل العملية الجماعية الكتابة فوق نتائجها لاحقًا.

التحقق: نجحت `npm run test:admin` مع اختبارات جديدة للتحديد عبر الصفحات وفي الهاتف، نافذة التأكيد الواحدة، استبعاد غير الجاهز للشحن، النجاح الجزئي وإعادة المحاولة، تنفيذ الطلب الجاري قبل الإيقاف، والمزامنة المعلقة. اختُبر تحميل أكثر من صفحة بيانات. لا أخطاء ESLint في الملفات المفحوصة، مع تحذيري `img` السابقين.

لا يلزم ترحيل SQL جديد. تُنشر التعديلات مع التطبيق، مع بقاء متطلبات الأقفال وإعدادات Ecotrack الموجودة سابقًا.

نجح فحص TypeScript بعد إعادة توليد أنواع Next.js عبر `next typegen`. كان ملف تحقق مولّد داخل `.next/dev/types` تالفًا؛ حُفظت نسخة منه في `/tmp/3abaa-dev-validator-before-bulk.txt` وأُزيل من ذاكرة التطوير المؤقتة، دون تعديل مصدر التطبيق لمعالجة ذلك.
